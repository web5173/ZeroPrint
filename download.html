Quick start

Quick Start

Three steps to get started and begin receiving print jobs.

1 · Install Client

Lightweight install, no registration required.

2 · Get Configuration

Copy the printer ID and public key from the ZeroPrint client.

3 · Send Print Job

Provide the printer ID and public key to your system. Send an HTTP request following the API docs to trigger printing.

FAQ

FAQ

ZeroPrint currently only offers a Windows client. In commercial printing scenarios, printer drivers and Office document processing have the most mature compatibility on the Windows platform, covering everything from traditional dot-matrix printers to modern receipt printers. There are no plans to develop for other platforms at this time. The client only needs to be installed on the Windows computer connected to the printer. Print jobs are initiated via standard HTTP requests with no restrictions on the source platform — Linux, Mac, mobile devices, or cloud services can all be used.
